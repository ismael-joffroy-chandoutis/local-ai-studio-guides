# Sources consultées

Ce registre accompagne les quatre guides. Les liens sont placés aussi près que possible des informations qu’ils documentent. Les prix sont des relevés de pages publiques, pas des devis ni des dépenses de contrôle. Les exemples de coûts sont calculés ; les conseils de séance sont présentés comme des propositions.

Toutes les consultations ci-dessous ont eu lieu le **23 septembre 2026, heure de Paris**. Une date de publication n’est indiquée que lorsqu’elle a été identifiée. Les manuels sans date restent utilisables comme sources primaires ; une date de consultation ne les transforme pas en publications de 2026. Les résultats de recherche non lus ne sont pas assimilés à des sources.

Une source partagée entre plusieurs guides apparaît une seule fois dans ce registre. Les branches `main` et les pages tarifaires restent modifiables après cette consultation.

## Ce que la vérification ne permet pas d’affirmer

Le port 42003 n’est pas établi comme shell universel de Pinokio. Le comportement exact des lanceurs n’a pas été testé sur les quatre tours. Aucun minimum de mémoire ni délai d’entraînement H3 sur ces Windows n’est établi. Le cas du LoRA sans effet rapporté dans la résidence reste sans cause démontrée publiquement. Aucun plafond de dépense individuel par clé fal n’a été confirmé. Les crédits Hailuo après connexion n’ont pas été inspectés.

Le formulaire de demande de licence H3 (`platform.minimax.io/h3-license`) n’a pas fourni de contenu textuel exploitable ; le guide renvoie à la FAQ officielle qui porte ce lien. Une demande ne prouve pas l’obtention d’une autorisation.

Les anciennes adresses du manuel Three.js sous `/manual/en/` n’étaient plus accessibles. Les liens retenus pointent vers le manuel actuel sous `/manual/pages/`.


## Vérification des fichiers livrés

Les cinq documents portent le même en-tête de version. Les liens locaux, les blocs de code et la présence des sources citées dans ce registre ont été contrôlés. Le code Python a été vérifié syntaxiquement sans appel payant. La logique du tableau a passé 15 contrôles : zoom, déplacement, recentrage, clic, clavier et sélection de vidéo. Le rendu dans un navigateur et le décodage d’une vidéo réelle n’ont pas pu être vérifiés, l’accès au navigateur étant bloqué dans cet environnement.
